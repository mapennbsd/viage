# Security

viage handles secrets, so reports of security problems are welcome.

Please report a vulnerability privately, with the "Report a
vulnerability" button on this repository's Security tab, not in a public
issue. Include the viage version (`viage -V`), your OS, the age version,
and the steps to reproduce it.

In scope is anything that puts the plaintext, the decrypted identity or
the passphrase somewhere viage says it does not go, or that defeats one
of the checks the README describes. The limits listed under "What it
protects against, and what it does not" are known and by design.

This is a one-person project; replies are best effort.
